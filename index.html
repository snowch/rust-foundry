Storage and recovery limits
32 files, 2 MB each, 8 MB total. TinyDB supports 4,096 rows and 256-byte storage pages. Normal exits save a complete workspace snapshot, including earlier commits when a later statement fails. Stop, traps, and timeouts retain the previous saved snapshot.
Browser storage can be denied or evicted. Download important files. Two tabs cannot overwrite the same saved revision. Journal interruption commands are deterministic teaching simulations; browser storage does not promise physical disk fsync or survival of a power loss.

Built for learning on phones and tablets.
A browser-only course using an experimental, pinned Rust compiler. TinyDB runs a small bundled Rust program; the full compiler downloads when you run Rust source. Single-file programs and the standard library are supported; external crates and procedural macros aren’t included. Target browsers are Safari on iPhone/iPad and Chrome on Android. The compiler is memory intensive; physical-device compatibility is still being verified. Keep this tab open while compiling.
