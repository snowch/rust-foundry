Built for experimenting on phones and tablets.
A browser-only MVP using an experimental, pinned Rust compiler. Single-file programs and the standard library; external crates and procedural macros aren’t included. Target browsers are Safari on iPhone/iPad and Chrome on Android. The compiler is memory intensive; real-device compatibility is still being verified. Keep this tab open while compiling.
